## 边界

- 本轮没有打开真实COM端口。PQC签名和KEM响应来自明确标识的哈希协议替身；真实双板签名、验签、算法切换、KEM和重新建钥仍需现场验证。
- 芯片1本次签名公钥在同一握手内交给芯片2，因此不宣称跨会话长期身份认证或防复制硬件身份。
- 图片业务数据未经过芯片UART；当前仍由同一Windows进程的内存记录层交付。双电脑TCP仍未实现。
- 通信记录的图片载荷只在内存中重组，验证后保存到应用临时附件目录供聊天显示；导出JSON保存元数据和哈希，不嵌入原始图片或密钥。
- 图片逐块完整密文HEX仅保留在当前进程内存，不写入导出JSON；导出仍保留逐块序号、报文头、密文长度和故障标记。
- 这是演示协议，不是TLS，也没有经过独立密码协议安全证明。
