# v0实施计划

**Goal:** 独立C程序实现双端签名、KEM、指纹核对、双向认证加密文本/文件与重新建钥。
**Architecture:** 可移植单端协议/流式业务核心；Windows GUI、socket/串口及OpenSSL后端分离。
**Tech Stack:** C99 / GCC / CMake / OpenSSL EVP / Win32 / WinSock。
**Spec:** design-v0.md。

- [ ] 共享接口：类型、错误、缓冲所有权、后端操作、传输回调和会话状态；仅新目录。
- [ ] 密码后端：先写已知答案/HKDF/签名/KEM失败测试，再实现成熟库调用；真实软件PQC与芯片算法标识隔离。
- [ ] LC01驱动：先写协议命令/帧校验/字节序测试，再实现单板串口与签名/KEM后端；密钥不经网络。
- [ ] 会话：先验证双端握手、篡改、重放、模式不符、未确认拒绝业务，再完成双向签名/KEM/确认与记录。
- [ ] 应用：原生GUI、两端单串口、文本、流式文件、接收确认、取消和换钥；后台不得直接访问窗口控件。
- [ ] 交付：自测、独立双进程loopback、负向路径、从TEMP运行、审查、许可证与打包校验；硬件/能耗待测明确列出。

用户已经授权按既定架构实施，直接连续执行；不另起已授权范围的确认流程。人工会话指纹确认属于产品协议本身，不能被一键连接绕过。
